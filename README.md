# ゼネコン帳票 取込・記入（試作）

ゼネコンの書式（PDF・スキャン画像）を背景にして、入力欄を四角で配置 → 記入 → 100%で印刷するアプリ。
静的ファイルだけ（ビルド不要）。`app/` をそのまま GitHub Pages などに置けば動く。

## 構成
- `app/index.html`・`app.css`・`app.js` … 本体
- `app/date-stamp.js` … Y-Format と同じデート印（SVG）
- `app/vendor/` … pdf.js 3.11.174（pdf.min.js / worker / cmaps / standard_fonts）。cmaps がないと日本語フォント非埋め込みのPDFで文字が出ない

## データの置き場所（試作の段階）
- 帳票（欄の配置）と背景画像 … ブラウザの IndexedDB（`genecon-forms`）
- 記入内容 … localStorage `gfa:v:<帳票id>`、共通情報 … `gfa:profile`
- 共有は「帳票ファイル（.json、背景画像込み）」の書き出し・読み込みで行う

## 欄の種類
文字（1行）／文字（複数行）／数値（3桁区切り）／日付（和暦・西暦・年だけ・月だけ・日だけ）／チェック・○囲み／デート印
- 共通情報から入れる（会社名・工事名など）、連動名（同じ名前の欄は同じ内容）、マス目（郵便番号など）、入りきらないときの自動縮小

## 書式の手直し（前の記入が残っている書式）
欄の配置画面の「書式の手直し」で、背景から記入済みの文字や○を消す。
- 文字を消す（PDFのみ）：取り込むときに **文字を描かずに描いたページ画像**（`<id>:<頁>:notext`）も作っておき、囲んだ範囲は「今の背景」と「文字なし画像」の明るいほう（canvas の `lighten`）にする → 文字だけ消え、罫線・下線・枠・○（図形）は残る
- 四角で消す／ブラシで消す：白く塗る（スキャン画像にも使える）。文字と重なった○はブラシで○の線だけなぞる
- 操作は記録（ops）で持ち、元に戻すは手直し開始時の画像に描き直し。最初の手直しで取り込んだときの画像を `<id>:<頁>:orig` に残し、「取り込んだときの状態に戻す」に使う
- 帳票ファイル（.json）には文字なし画像を入れていないので、読み込んだ帳票では「文字を消す」は使えない

## ローカルで試す
```
cd app
python -m http.server 8765
```
→ http://127.0.0.1:8765/
